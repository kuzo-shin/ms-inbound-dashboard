구글 시트 실시간 자동 동기화 설정

💡 1분 만에 끝내는 무료 클라우드 서버 만들기 (최초 1회)
  1. 개인 구글 계정으로 새 구글 스프레드시트를 하나 만들고 상단 메뉴 [확장 프로그램] ➔ [Apps Script]를 클릭합니다.
  2. 기존 코드를 지우고 우측 상단 [연동 스크립트 코드 복사] 버튼을 눌러 복사한 코드를 붙여넣은 뒤 저장(💾)합니다.
  3. 우측 상단 [배포] ➔ [새 배포] 클릭 ➔ 유형: 웹 앱 / 다음 사용자로 실행: 나 / 액세스 권한: 모든 사용자(Anyone) 선택 후 배포합니다.
  4. 발급된 웹 앱 URL(https://script.google.com/macros/s/.../exec)을 아래 칸에 붙여넣거나, 코드 상단 DEFAULT_CLOUD_URL에 넣어두면 모든 팀원에게 영구 적용됩니다!
